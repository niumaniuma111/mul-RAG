# ★ v1.1.8：移除 passlib[bcrypt]==1.7.4，改为直接依赖 bcrypt。
#   原因：passlib 1.7.4（2020 年后未更新）在加载 bcrypt 后端时会用一个
#   >72 字节的固定测试串做自检（detect_wrap_bug），而 bcrypt>=4.1 把
#   "超 72 字节"从静默截断改成了抛异常 —— 于是**任何一次密码哈希都直接 500**，
#   报错点在 passlib 内部，离业务代码很远。
#   实测版本组合：passlib 1.7.4 + bcrypt 5.0.0 → ValueError。
#   直接用 bcrypt 少一层依赖，且 bcrypt 本来就是 passlib[bcrypt] 的传递依赖。
#   代码见 app/core/security.py；注意调用前要自己截断到 72 字节。
bcrypt==5.0.0
python-dotenv==1.0.1
pyyaml==6.0.2
