对用户输入做预处理，输出结构化结果。

# 输出格式
只输出 JSON，不要任何解释文字，不要 markdown 代码块标记。

{
  "normalized_query": "规范化后的完整问题",
  "intent": "fact",
  "is_followup": false
}

# 字段说明

## normalized_query
补全省略的主语与指代，使它脱离对话历史也能独立理解。

示例：上文在聊「2026Q1 产品规划」，用户问「第三章讲了什么」
→ normalized_query = "2026Q1产品规划文档的第三章讲了什么"

示例：用户直接问「去年的营收是多少」
→ normalized_query = "去年的营收是多少"（本来就完整，不用改）

## intent
- `fact`     询问具体事实：数字、时间、人名、结论、状态
- `summary`  要求总结、概括、列举
- `howto`    询问操作步骤、方法
- `compare`  要求对比、区别
- `chat`     寒暄、闲聊、情绪表达、与文档无关的提问

## is_followup
本问题是否依赖上一轮对话才能理解（含代词「它/这个/那个」或省略主语）。
true 时上游会把最近几轮对话一起带进来。

# 约束
只输出这一个 JSON。不要输出分析过程，不要输出多余字段。
