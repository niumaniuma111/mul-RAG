# ============================================================
# 中文停用词表（BM25 稀疏检索用）
# ------------------------------------------------------------
# 用途：jieba 分词后过滤掉这些词，再构建 BM25 的稀疏向量。
#
# 为什么必须过滤：
#   稀疏向量是按「词 → 权重」存的。如果"的"、"了"、"是"这些高频虚词也入索引，
#   它们会出现在几乎每一段文本里，IDF 趋近于 0，看似无害 —— 但词表会被撑大，
#   稀疏向量的维度上升，检索与存储成本都变高，而且容易产生虚假的共现匹配。
#
# ⚠️ 注意不要误删领域实义词。例如"同比"、"环比"在通用语料里是虚词，
#    但在财务文档里是实义词，所以这里**没有**收录它们。
# ============================================================
